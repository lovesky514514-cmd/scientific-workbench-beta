SKY WORKBENCH / 2026-11-16

4.0 版本更新

在 3.1 的草案、审核和受控求解基础上，4.0 由科研总控组织专家协作，并把求解中的网格和完成后的科学证据带回工作台。

01 / 更新内容

从计划到结果，证据更容易核对

  • 科研总控与动态专家。总控根据任务和现有证据安排专家，遇到分歧可要求补证或定向返工。真实求解仍需用户审核计划并显式 RUN。
  • 原生 COMSOL 模型视图。Heat 求解期间查看当前尝试发布的网格。已审核的三维结果可查看温度色标、原始结果图和证据记录。
  • 独立科学审核。对照冻结模型、求解记录和数值检查核对结论。成果包包含模型、原始数据、图像、报告及文件校验清单。
  • 诊断与数据读回。恢复专家可识别不同来源的状态冲突并给出处理建议。大型科学数组经有界文件传输读回，宿主核对运行身份、大小和哈希。

02 / 使用方式

从一句铁块冷却问题开始

“我想做一个 3 × 3 × 20 mm 的烧红铁块，分析它随时间的温度变化。”

在任务页保留已知尺寸，审阅初温、环境温度、材料属性、对流和辐射条件。通过预检并授权运行后，在模型页查看网格，在结果页查看温度场，在证据页查看审核记录。

“烧红”需要在计划中明确为数值温度。换热和辐射参数也要按具体工况确认，实际结果只适用于该次审核过的模型条件。

03 / 验证记录

本次做了哪些验证

COMSOL 6.3 三维瞬态冷却
一个获授权的 RUN 完成四次内部求解及 16 项独立物理检查。1366 × 768 和 1440 × 900 两档原生窗口均显示了已审核的最终温度场。
Windows 桌面
在具备可用 WebView2 的 Windows 上，完成 3.1→4.0 升级、干净安装、原生启动、退出和卸载。卸载后核对项目数据库与配置。
禁网 Windows Sandbox
临时加载微软签名的固定版 WebView2 后，同一安装包完成安装、原生启动、Python 最小算例和卸载，算例输出 385。
代码回归
Python 2261 项通过，14 项既有跳过。前端 138 项、Rust 5 项通过，TypeScript 类型检查通过。

科学验收覆盖上述 COMSOL 6.3 热算例。沙箱最小算例验证桌面和本地脚本执行链。

04 / 能力范围

按具体引擎和模型判断

三维温度场实测使用 COMSOL 6.3。COMSOL 6.4 和其他科学引擎需按版本、模型与本机许可分别验收。外部智能体通信的验证使用本地模拟环境。

内置 Evergreen WebView2 在无现成运行时的 Windows 上仍需完成离线安装实测。
