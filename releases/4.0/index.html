SKY Workbench 4.0.0 源码版

4.0 由科研总控协调动态专家、计划审批和证据核查。COMSOL 模型视图可读取活动运行的网格检查点，结果视图可查看已审核 Heat 的三维温度场。

已通过的专项验收

  • 一项 COMSOL 6.3 三维瞬态冷却，完成四次内部求解和 16 项独立物理检查。两档 Windows 窗口均显示已审核温度场。
  • 在具备可用 WebView2 的 Windows 上完成 3.1→4.0 升级、安装、启动和卸载，项目数据通过完整性核对。
  • 禁网 Windows Sandbox 临时加载微软签名的固定版 WebView2 后完成安装、原生启动、Python 最小算例与卸载。算例输出 385。
