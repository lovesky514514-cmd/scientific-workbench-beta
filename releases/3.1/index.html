SKY WORKBENCH / 2026-11-01

3.1 版本更新

在 3.0 基础上，让不完整的建模想法更容易形成可审阅的方案，并把真实 AI、受控执行与结果证据连接起来。

01 / 更新内容

从草案到求解，步骤更清楚

  • 真实云模型接入：DeepSeek 完成文本、流式、JSON 和 ScientificPlan 四项真实推理检查，完善云端响应协议及冻结运行时连接。
  • 可审阅的候选补参：信息不足时继续生成模型草案，AI 提出带单位、理由和适用条件的候选值。建议不会覆盖用户已给的事实，也不会自动成为已验证数据。
  • 单位与授权检查：执行前检查单位和参数使用授权；计划修改后重新审核，只有显式 RUN 才开始求解。截断或空白 JSON 最多向同一云服务、同一模型重试一次。
  • 数值检查改进：铁块冷却保留对流与灰体辐射。用户结果输出和内部能量校验分别采样，稀疏输出不再直接承担能量积分；三维资源预估按实际执行器识别。
  • 多引擎任务组织：围绕 COMSOL、MATLAB、VASP、Materials Studio、LAMMPS 与 Mathics3 展示对应能力和状态，分别判断检测、输入、运行与科学结果。

02 / 使用方式

一句话，也可以开始建模

“我想做一个3x3x20mm的烧红的铁块，现在想分析热变化。”

先保留已知尺寸，再建议初温、环境温度、热物性、换热系数、辐射率和时长。用户审核这些值及建模选择，通过预检后显式 RUN，最后检查温度历史、模型读回与数值证据。

“烧红”没有唯一的数值温度，AI 给出的值属于可修改假设。恒定材料属性、空气冷却和无支撑接触等条件同样需要审核，不能从一句描述中假装得到实测材料数据。

04 / 能力范围

按具体引擎和模型判断

MATLAB、VASP、Materials Studio 本轮缺少可用环境，真实求解按缺失软件跳过，未记为成功。LAMMPS 水 TIP4P、铜 EAM 等需要对应适配；Mathics3 数学执行也不等于自动完成任意物理建模。

接触、多域耦合、复杂材料、反应或交叉扩散等需分别建立执行器与验收。一次 AI 建议的 10 cm 铁块在 600 s 测试预算内尚未完成，其尺度性能未认证。数值一致性检查不替代材料实验标定。目标电脑安装、重启、升级与实际界面交互仍需验证。
