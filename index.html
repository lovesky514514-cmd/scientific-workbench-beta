PRIVACY / MINIMAL BY DESIGN

只留下必要信息。

这是一份供内测使用的简明隐私说明，正式对外开放前应补充运营主体与联系渠道。

我们收集什么？

陌生人申请时收集其主动提交的邮箱及测试兴趣；批准后分配三位测试编号。受邀者提交反馈时收集问题分类、描述、错误代码与可选客户端版本。我们不会要求姓名、手机号、COMSOL 许可证、模型文件或完整日志。

为什么要收集？

邮箱仅用于人工发送邀请码和内测相关通知，测试编号用于区分反馈来源，问题内容用于定位软件错误。

如何保存、访问及删除？

申请与反馈保存在私有 Cloudflare D1 数据库中，仅受限管理员可查看。申请邮箱和反馈正文默认在创建满 90 天后由后台定时清理；测试编号及撤销状态保留用于席位防重复发放。用户可通过项目发布的联系邮箱申请删除数据；部署时必须配置实际联系地址。

还有哪些技术数据？

Cloudflare 与 GitHub 作为托管服务提供商可能处理网站请求 IP 等技术信息；我们不将原始访问 IP 写入申请和反馈记录。短期防滥用标识如启用，仅以不可逆每日散列储存并清理。

注意事项

反馈文本脱敏只是尽力过滤，不保证任何粘贴日志都能彻底清除敏感信息；请先自行删去敏感部分。不收集直接身份信息不等于绝对匿名。测试邀请码和反馈编号均属于假名化标识。请不要提交敏感模型、组织内部数据或私人路径。
