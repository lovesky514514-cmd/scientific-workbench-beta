SKY Workbench V2.0 把自然语言任务、科学建模计划、COMSOL 模型读回和可审阅证据放在同一工作空间。它是独立第三方工具，不能替代 COMSOL 许可、求解器判断或研究者的科学审核。

WORKFLOW

从请求到可核查的结果

用户始终保留计划确认、运行中干预和结果复核权。每一步是否可执行，取决于实际环境与证据。

  1. 01

    提出任务

    输入目标、几何、材料与边界条件；缺少必需信息时明确提示，不猜测物理量。

  2. 02

    审阅计划

    检查参数单位、所选 Physics、边界映射和求解设置。人工批准表示允许执行，不等于科学验证。

  3. 03

    本地执行

    在具备许可的 COMSOL 安装上构建与求解，按当前 run/attempt 记录模型读回、进度和诊断。

  4. 04

    核查证据

    分别报告命令执行、模型状态和科学验证；缺失证据应为不可验证，而非“成功”。

CAPABILITIES

围绕科学工作，而非聊天窗口

01 / MODEL

导入与模型工作区

导入 MPH 后保留来源身份；新建项目与导入模型分区展示。实际可修改范围以模型读回和当前支持的操作为准。

02 / CONTROL

可中断的执行

运行中的暂停、取消与恢复均应有明确状态；不把旧 attempt 的产物认证为当前结果。

03 / EVIDENCE

结果与模型卡

图像、模型文件、哈希、求解诊断及科学检查分开呈现，帮助研究者追溯结论。

DOCUMENTATION

使用之前，先了解边界。

文档覆盖环境要求、COMSOL 集成、MPH 导入、证据语义和故障诊断。公开源码不包含 Windows 安装包。
