GUIDES / 使用文档

文档总览快速开始工作流程验证与证据COMSOL 兼容性故障排查研究与论文常见问题

Runtime 无法启动

核对确切软件版本、运行依赖和安装日志。等待正式发行后，优先对照 Release 中的 SHA-256。不要把旧版 sidecar 复制到新版本里尝试绕过问题。

Java Bridge 返回 401

缺少、错误或格式非法的令牌，本来就应返回 401。不要通过关闭鉴权或公开本地端口来“修复”。使用 Workbench 已实现的授权连接流程。

COMSOL 无法连接

检查 COMSOL 是否本地安装、版本及模块是否满足要求、用户是否拥有相应许可，以及所配置的位置是否正确。不要将 COMSOL 专有文件手动上传到项目仓库。

模型读回通过却显示 UNVERIFIABLE

这通常意味着部分执行或状态证据可用，但科学检查、mesh/DOF、求解记录或 artifact 归属尚未完整。严格成功需要四个条件同时满足。

如何提交反馈

邮件联系 swbtest001@yeah.net，只提供版本、操作系统、错误类别和最小复现步骤。请脱敏处理路径、模型名称、令牌、API key、许可证文件和研究数据。
