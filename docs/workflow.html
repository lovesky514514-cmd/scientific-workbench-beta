ASK / PLAN / RUN

阶段主要目标不能推断什么
ASK理解请求和澄清模糊条件不能把模型回答当作实际 COMSOL 状态
PLAN生成 ScientificPlan，说明要建什么计划被接受不等于已执行
RUN通过受控 Runtime 与 COMSOL 执行允许的操作接口执行完成不等于科学结果通过

ScientificPlan 应包含哪些内容

面向一个实际研究问题，规划应明确几何、物理接口、材料及数值参数、单位、边界条件、selection、网格、研究类型、求解器设置、输出和科学验证标准。缺失或歧义信息需要先澄清。

模型读回（Readback）

模型树读回从真实的 COMSOL 模型中核对事实。尤其要注意：边界编号和选择集并不一定稳定，API 节点创建成功也不代表物理条件已经对正确的对象生效。

处理不确定情况

遇到模型能力不支持、输入不充分、证据缺失或科学检查失败时，应明确给出 FAILED、UNVERIFIABLE、需要修复或升级的状态，而不是默认报告成功。

实际支持哪些自动化建模与求解动作，以未来具体发行版的说明和真实验收为准。本页介绍的是系统工作流，不保证任意物理问题都可以一键建模。
