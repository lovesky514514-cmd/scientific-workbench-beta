COMSOL 兼容性

明确已验证范围，不把单台计算机上的只读测试扩展为全版本兼容声明。

文档总览快速开始工作流程验证与证据COMSOL 兼容性故障排查研究与论文常见问题

目前有记录的环境

内部 RC5.2 候选验收使用 Windows x64 主机与 COMSOL 6.3，检查了授权启动、模型树只读读回及关停。它不是所有 COMSOL 模块、工作流或操作系统的兼容性证明。

尚未验证的范围

  • 其他 COMSOL 版本及所有增量更新的兼容性。
  • 所有物理接口和插件的可用性。
  • 任意复杂模型的修改、求解与科学正确性。
  • 最终公众版 Setup 的安装、激活、关闭和卸载。

许可证与分发

用户应自行安装并合法授权 COMSOL。Workbench 不附带 COMSOL 安装包，也不授予使用 COMSOL 的权利。这个独立研究项目不是 COMSOL 官方产品。

有关软件的 API/Application 发行方式，请参考 COMSOL 官方软件许可协议；源码和 EXE 发行方案必须在适用权利确认后确定。

现阶段不要把源码仓库是否公开，与 COMSOL 集成模块及 EXE 是否获准分发混为一谈。
