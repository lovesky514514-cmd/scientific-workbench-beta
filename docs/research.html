研究与论文

研究重点是“执行成功”与“可信科学结论”之间的证据边界。

文档总览快速开始工作流程验证与证据COMSOL 兼容性故障排查研究与论文常见问题

Scientific Workbench 的研究主线：科学仿真智能体不应仅凭一个 API 返回或求解器收敛，就向用户宣称已经得到了可靠的科学结果。

研究问题

如何通过结构化计划、真实 COMSOL 模型状态读回、科学验证和运行证据归属，为每一次科学自动化执行建立更有依据的成功判断。

已有历史实验线索

  • 较小模型的修复可能改善平均评分，同时产生关键安全回退。
  • 增大模型规模并不保证每个问题上都单调改善。
  • 静态路由可能选错能力级别；严格输出门也可能导致过度拒绝。
  • 真实 COMSOL 的历史实验显示：科学检查通过仍可能因证据不完整而标为不可验证。

这些观察来自多个独立的历史队列，不能直接合并为统一成功率；它们不代表当前 RC5.2 的完整科研结果。

研究论文状态

论文以 LaTeX 继续编辑。历史十组已选 case-level 指标已经做过汇总复算，但部分耗时、显存、数值场及历史产品证据仍待独立核验，相关工作引用与前瞻性对照实验也尚未完整，因此不是正式发表的论文。

公开科学数据的原则

只有在确认版权、隐私和第三方许可允许后，才公开实验脚本及脱敏结果。不要直接发布原始 COMSOL 模型、私人知识库或真实运行日志。
