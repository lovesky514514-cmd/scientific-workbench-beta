GUIDES / 使用文档

文档总览快速开始工作流程验证与证据COMSOL 兼容性故障排查研究与论文常见问题

Scientific Workbench 是面向本地科学建模的研究工作台。文档既介绍操作流程，也明确哪些能力已测试、哪些仍处于内部候选阶段。

当前公开的只是介绍网站和文档。RC5.2 的公开源码、安装程序及正式发行尚未获得批准，因此文档不提供不存在的下载按钮或安装命令。

建议阅读顺序

  1. 快速开始：了解 COMSOL 安装、授权和发行状态。
  2. 工作流程：认识 ASK / PLAN / RUN 与结构化 ScientificPlan。
  3. 验证与证据：理解四项可靠性条件，以及何时应标记 UNVERIFIABLE。
  4. 版本与环境：区分已测试范围和未验证范围。
  5. 故障排查：定位 Runtime、Java Bridge 和模型读回问题。

软件和 COMSOL 的关系

本项目不会提供 COMSOL 软件、许可证或其专有运行库。实际的 COMSOL 建模功能，需要使用者自行取得符合相关许可协议的安装及必要模块。它也不是 COMSOL 官方出品。

反馈与帮助

可以通过 swbtest001@yeah.net 联系维护者；反馈时只提交最小复现步骤和脱敏后的错误描述，不要发送密钥、私人模型或完整运行日志。
