DOCUMENTATION / V2.0

SKY Workbench 文档中心

从环境准备到模型证据，按实际操作顺序查找信息。本文档说明当前 V2.0 内部候选的使用边界；具体科学结果只能由当前运行的真实证据支持。

01 / 概览

产品边界

Scientific Workbench 是本地优先的独立科学建模工作台。Python Scientific Runtime 管理计划、任务状态与科学检查；Java Bridge 靠近 COMSOL Model API 执行受控读回与操作；Tauri 负责桌面启动和自有进程生命周期。它不内置 COMSOL 安装文件、JAR、许可证或私有知识库。

不要混淆三种状态

Command Success、Model State Verified 与 Scientific Validation Passed 是独立判断。任一必需证据缺失时，不应把结果显示为科学通过。

02 / 开始

环境与安装

  • 当前桌面安装生命周期已在 Windows 11 x64 测试；其他系统不应据此推定已验收。用户工作区需可写。
  • 真实建模需要用户另行安装 COMSOL 6.3，并具备适用的有效许可证及模块权限；源码和安装包都不提供 COMSOL 本体或许可证。
  • 本地模型能力取决于实际 Ollama 服务和所选模型。模型权重不随源码分发；缺失时应显示 Unavailable，不静默切换。
  • 桌面界面依赖 WebView2。若系统缺失，其安装可能需要联网获取运行时；Python 原生组件还需系统提供适用的 Visual C++ 2015–2022 x64 运行库。
  • Windows Setup 仅通过批准的内部渠道提供；公开源码不包含安装包，也不得将旧 RC 安装包当作 V2.0。

03 / 开始

首次启动与预检

启动后分别检查 Scientific Runtime、COMSOL/Java Bridge、本地 Ollama/模型和可写工作区。Ready、Degraded、Blocked、Unavailable 只描述本机实际检测结果；成功打开界面不证明 COMSOL 已连接或模型已可用。若 Runtime 未连接，应查看可见错误、使用应用内帮助及 Open Logs，必要时选择 Restart Runtime；中断的运行不能据此标记完成。分享日志前请删去凭据、私人路径与模型信息。

04 / 工作流

新建项目与导入 MPH

新建任务后，在任务区域输入自然语言要求；执行前核查 Scientific Plan 的几何、材料、物理场、边界、网格/研究、单位、假设与必需验证检查。尺寸、单位或选区不明确时应修正计划。人工批准只表示允许执行，不等于科学认证。

导入 MPH 时保留原文件，导入项目与新建项目分区展示。预览或模型树读回不等于可以覆盖原件；当前候选版不提供通用的任意 MPH 导入后修改流程。仅在具体操作受支持并已审阅时，才对副本修改并重新读回、验证；对象身份映射不可靠时应停止修改。

05 / 工作流

COMSOL 集成与本地鉴权

桌面端为本地 Runtime 生成独立会话令牌；Java Bridge 使用另外的高熵令牌，所有 HTTP context 都要求鉴权。只监听 127.0.0.1 并不能替代令牌。Bridge 与 COMSOL 的实际可用性必须由本机环境检测和 live readback 决定，不能从软件包内存在源码推断。

许可提醒

本项目与 COMSOL 无隶属关系。公开发行所需的 COMSOL API/应用分发边界仍待负责人和权利方确认。

06 / 工作流

执行控制、结果与证据

运行中，“暂停”请求在经验证的安全点停止；只有确认进入 Paused 后才能 Resume。“停止”结束当前 attempt，不是可继续的暂停。新 attempt 必须产生自己的证据，不能继承旧 attempt 的认证。

结果图片、模型读回、当前 run/attempt 身份、产物哈希与 Model Card 应一起检查。Command Success、Model State Verified、Scientific Validation Passed 及证据完整性是独立检查。即使存在 PNG 或 MPH，证据缺失、失效或属于旧尝试时仍为 Unverifiable/Unavailable，不能填入假零值或复制历史结论。

07 / 支持

故障诊断

COMSOL 不可用
确认另行安装的 COMSOL 6.3、有效许可与模块权限，再运行环境检测。发现可执行文件不等于 Bridge 已连接或模型已读回；不要将专有 JAR 复制进发行包。
Java Bridge 断开
先确认 COMSOL 可用，再查看 Bridge 状态与诊断。仅能连接本地端口不代表通过本地鉴权，也不代表模型已验证。
Runtime 启动失败
在应用内打开 Open Logs，必要时使用 Restart Runtime，检查端口占用、写入权限和自有进程清理结果。活动运行被中断时不得标记为 Completed。
Ollama 或模型不可用
检查本地 Ollama 服务及设置中的所选模型；模型下载需明确确认，不应假定自动回退到其他模型。
计划需审核
执行前核对单位、几何、材料、边界、选区身份、假设及验证检查。审批不是科学认证。
暂停或停止响应延迟
暂停需等待安全点；停止后应等待清理结果。不要手工终止不属于本工作台的 COMSOL 或 Java 进程。
模型或结果不可验证
核对当前 session/run/attempt、证据状态与 artifact manifest。旧图像或文件存在不能认证本次运行。
导入 MPH 报错
保留原件和错误日志；先只读检查兼容性。当前版本不支持任意 MPH 的通用修改。
向支持渠道提供什么？

可提供产品与 Windows 版本、环境状态、失败阶段和最小脱敏日志。不要公开发送 API Key、Token、私人 MPH、知识库、许可证材料或完整本机路径。

发行状态、许可与隐私

SKY Workbench V2.0 源码及公开使用文档见 GitHub 仓库。仓库中的第一方代码以 Apache-2.0 提供；历史 MIT 通知、素材许可和第三方 NOTICE 各按其原条款保留。源码公开不等于 Windows 安装包已公开发行。

Windows Setup 仅内部提供，本站不提供 EXE 下载。真实 COMSOL 执行需要用户自行安装并合法授权 COMSOL 6.3；本项目与 COMSOL AB 无隶属或官方认证关系。需要咨询内部测试请联系 swbtest001@yeah.net。旧内测服务不作为本站功能。
