常见问题

关于安装、开源、模型支持及科学结果最常被问到的问题。

文档总览快速开始工作流程验证与证据COMSOL 兼容性故障排查研究与论文常见问题

Workbench 是否包含 COMSOL？

不包含。用户应自行获取合法的 COMSOL 安装与适用模块。Workbench 不是 COMSOL 官方软件。

现在可以直接下载 EXE 吗？

还不行。公开安装包仍在安全、许可与安装生命周期验收流程中。官网不会提供旧的受控测试下载入口，也不会伪造一个可用下载按钮。

源代码已经全部开源了吗？

网站源码位于 GitHub；完整 Workbench 源码及 COMSOL API 集成模块的公开许可还在审查中。请不要将公开的网站仓库理解为完整软件已经开源。

为什么需要四道验证条件？

因为操作成功、模型正确、数值可信与证据可追溯是不同问题。缺少其中一项，就不能据此认定严格科学成功。

能够支持所有 COMSOL 物理场吗？

不能这样承诺。实际支持范围应以具体发行版和真实测试证据为准；未测试的物理场或动作需要明确标注。

如何反馈问题？

发送邮件至 swbtest001@yeah.net，并请删除私人模型、密钥和本机路径等敏感信息。
