验证与证据

严格成功不是一个界面状态，而是四个条件同时成立。

科学仿真最危险的错误，有时不是程序崩溃，而是模型或结果看似合理，却无法证明它对应了正确的任务。

四项可靠性条件

条件实际检查
Command Success操作是否真正执行完成。
Model State Verified模型真实状态是否与计划相符。
Scientific Validation数值、物理和边界行为是否满足预先规定的条件。
Evidence Contractmesh、DOF、solver、结果和 artifact 是否绑定到正确 run/attempt。

严格成功要求四项均为真。 当可用证据不足时，不应把状态改写成通过。

如何理解结果状态

PASS：根据指定的可靠性契约有足够的证据支持严格成功。
FAILED：执行、模型状态或科学检查等关键条件明确不满足。
UNVERIFIABLE：无法得到必要证据，不能确认成功。

为什么求解器收敛还不够？

一个求解器可能在错误的边界选择、材料或物理设定上收敛。也可能数值看来正确，但实际网格、DOF 或运行归属缺失。工作台的目标是把这些差别清晰显示出来。

当前候选的验证边界

最新 RC5.2 审计已报告本机 Runtime、鉴权和授权只读 COMSOL 6.3 模型树读回测试通过。它没有在该轮重新进行科学求解，也没有进行正式 Setup 的安装、激活和卸载验收。
